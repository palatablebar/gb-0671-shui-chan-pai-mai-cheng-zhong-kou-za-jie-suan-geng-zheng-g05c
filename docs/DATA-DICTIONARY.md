# 数据定义

票号与原始编号均为字符串，保留前导零。称重支持 kg、公斤与 t，统一为 kg，单价为 CNY/kg。
毛重与皮重按票号和版本配对，品类、单价、扣杂率与更正目标必须一致。计价重量=(毛重−皮重)×(1−扣杂率)，先量化到0.001kg，再乘单价，金额四舍五入到0.01CNY。
每票第一版不填写 replaces。后续版本只能替代当前生效版，分支或缺基版整票阻断结算。已支付额为各版本中最大累计已付值，待付=最终应付−累计已付；负待付表示待收回。
同编号同原值仅计一次；同编号不同原值全部隔离。空文件、全空行和仅表头分别报错。原始输入计数包括空行及重复表头，对账会分别解释。
归档封存保存逐版证据、隔离原因和运行摘要，非支付执行系统。数据使用虚构编号，不连接实际支付渠道。

## 跨日承接（M8）

封账通过 `POST /api/runs/{run_id}/seal` 固化不可变快照（`seals` 表，含封账封存码、逐票生效金额与版本审计），重复封存同一批号不新增记录，复核版本变化不改变封存码。重开昨日封账不被允许，迟到更正只以承接差额进入次日。

承接草稿由封账批次与次日批次的生效票逐票比较生成。票级字段：`base_version/current_version`（封账版本→更正版本）、`base_amount/current_amount`、`delta_amount`（应付差额）、`delta_paid`（已付差额）、`delta_due`（承接差额，负为应收回款）。票级闭合要求 `delta_amount = delta_paid + delta_due`；批级闭合要求承接票差额合计等于两批生效票总额差（次日新票计入 `new_tickets/new_total`，不进承接差额）。

三类阻断只保留待处理、不进承接结果：缺前版（`MISSING_BASE`，含未声明 replaces）、陈旧更正（`STALE_CORRECTION`，替代目标不等于封账生效版）、同一更正重复到达（`DUPLICATE_CORRECTION`，同票同版同替代目标在两批审计中累计超过正常两次）；票级或批级 `delta` 对不上账记 `UNBALANCED_DELTA`。

承接记录存 `carryovers` 表，主键为（封账批号 × 次日批号）。次日重跑同一对批号不新增记录；已发布记录不可被重跑覆盖。发布仅接受闭合草稿，事务化写入，失败整体回滚，旧版封账与原证据保持不变。封存下载 `GET /api/export/{run_id}` 在存在承接记录时附加 `carryover.json`。
